常见问题

开始写作之前，你可能想知道

作者管家会把小说上传到服务器吗？

不会。作品以普通文件保存在你选择的本地小说库中。只有主动调用 AI 时，相关上下文才会发送到你配置的 API 服务。

必须使用固定的小说目录结构吗？

作品需要包含“正文”目录。新建作品时会自动创建所需目录；已有作品也可以直接选择并由应用补齐。

可以使用自己的 AI 模型和接口吗？

可以。在设置中填写兼容接口地址、模型名称、API Key 和推理强度即可，不依赖 Codex CLI。

如何备份和同步小说？

你可以把作品目录纳入 Git 仓库，并通过应用内同步按钮执行拉取与推送。遇到冲突时会停止同步并提示手动合并。
